🌟 Fitur Utama

  • Backup Otomatis: Jadwalkan cadangan konfigurasi MikroTik (export, backup, script)
  • Simulasi Aman: Uji alur tanpa koneksi ke router fisik — ideal untuk pelatihan & demo
  • Perbandingan Versi: Deteksi perubahan konfigurasi (diff) dan pelacakan who changed what & when
  • Baseline & Compliance: Tetapkan konfigurasi standar (baseline), lakukan audit otomatis
  • Dashboard Real-Time: Status router, riwayat backup, insiden risiko tinggi, log aktivitas
  • Multi-Role Access Control: Admin, Operator, Auditor — dengan hak akses granular
  • Keamanan Bawaan: Enkripsi kredensial, CSRF protection, rate limiting, logging lengkap

⚙️ Persiapan Instalasi

Prasyarat

  • Python ≥ 3.10
  • pip (terinstal bersama Python)

Langkah Instalasi (Local Development / Lab)

cd mikrotik-backup-main
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
flask init-db --seed-demo
flask create-admin sigapadmin --role admin

Catatan: Data demo (router simulasi, baseline, insiden contoh) akan dibuat otomatis.

▶️ Menjalankan Aplikasi

Mode Simulasi (Aman & Ideal untuk Video/Demo)

SIMULATION=1 flask run --host=0.0.0.0:5000 --debug

✅ Akses dashboard di: http://localhost:5000
✅ Login dengan akun yang dibuat tadi (sigapadmin + password Anda)

Mode Produksi (Router Nyata)

  1. Isi kredensial router di Admin > Devices > Tambah Router
  2. Pastikan port 8728 (API) atau 22 (SSH) terbuka dari server SIGAP-NET ke router
  3. Jalankan tanpa SIMULATION=1:
flask run --host=0.0.0.0:5000
