🌟 Fitur Utama

  • Backup Otomatis: Jadwalkan cadangan konfigurasi MikroTik (export, backup, script)
  • Simulasi Aman: Uji alur tanpa koneksi ke router fisik — ideal untuk pelatihan & demo
  • Perbandingan Versi: Deteksi perubahan konfigurasi (diff) dan pelacakan who changed what & when
  • Baseline & Compliance: Tetapkan konfigurasi standar (baseline), lakukan audit otomatis
  • Dashboard Real-Time: Status router, riwayat backup, insiden risiko tinggi, log aktivitas
  • Multi-Role Access Control: Admin, Operator, Auditor — dengan hak akses granular
  • Keamanan Bawaan: Enkripsi kredensial, CSRF protection, rate limiting, logging lengkap

⚙️ Persiapan Instalasi

Prasyarat

  • Python 3.12 atau lebih baru (dikembangkan dengan Python 3.13)
  • pip (terinstal bersama Python)
  • (Opsional) Docker (untuk mode containerized)

Langkah Instalasi (Local Development / Lab)

cd mikrotik-backup-main
pip install -r requirements.txt
python -m flask --app app init-db
python -m flask --app app create-admin sigapadmin

Catatan: Tanpa virtual environment dan tanpa file .env — SQLite di data/sigapnet.db dipakai otomatis. Password admin diminta tersembunyi saat create-admin dijalankan (min 12 karakter, huruf besar + kecil + angka + simbol); argumen hanya username. Tambahkan opsi --seed-demo pada init-db bila ingin data demo (router simulasi, baseline, insiden contoh) ikut dibuat.

▶️ Menjalankan Aplikasi

Mode Development (Lokal / Lab)

python -m flask --app app run --debug

✅ Akses dashboard di: http://localhost:5000
✅ Login dengan akun yang dibuat tadi (sigapadmin + password Anda)

Mode Produksi (Router Nyata)

  1. Isi kredensial router di Admin > Devices > Tambah Router
  2. Pastikan port 8728 (API) atau 22 (SSH) terbuka dari server SIGAP-NET ke router
  3. Jalankan aplikasi:
python -m flask --app app run --host 0.0.0.0 --port 5000

📁 Struktur Direktori (Singkat)

mikrotik-backup-main/
├── app.py                ← Entrypoint utama (Flask)
├── config.py             ← Konfigurasi: DB, enkripsi, path, mode simulasi
├── routes/               ← Modul API & halaman web (devices, backups, audits)
├── services/             ← Logika bisnis: simulasi, audit, integritas, risiko
├── templates/            ← HTML Jinja2 (dashboard, form, report)
├── static/                 ← CSS, JS, gambar

└── README.md             ← Anda sedang membacanya 😊

🛑 Troubleshooting Umum

MasalahSolusi
flask tidak dikenalGunakan python -m flask --app app ... — tidak perlu flask di PATH dan tidak perlu virtual environment
Database error saat init-dbPastikan data/sigapnet.db tidak dikunci proses lain, lalu ulangi python -m flask --app app init-db
Login gagal meski password benarThrottle login: 5 percobaan gagal per 5 menit per IP/username (tabel login_attempts). SECRET_KEY dibuat otomatis di file .secret_key — jangan dihapus agar sesi tetap valid
Router simulasi tidak munculBuat perangkat dengan mode Simulasi (adapter simulation) lewat form Tambah Router
